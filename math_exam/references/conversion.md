# PDF·이미지 변환과 통합

1. 학년도/과목/홀수·짝수/문항 수/쪽 수를 확인한다. 원문 PDF와 사용자가 제공한 HWPX 양식은 읽기 전용으로 보존한다.
2. `extract_pdf.py 원본.pdf work/새추출폴더`는 각 쪽 2배 이미지와 본문 span·char·행 좌표를 저장한다. math_candidate는 글꼴명에 EQ가 있다는 후보 표시일 뿐이다. 스캔 PDF는 AI 시각 판독 또는 사용 가능한 OCR로 전사한다.
3. 문항별 본문·수식·선택지·배점·그림·안내문·저작권을 목록화한다. PDF의 독자 인코딩 글자는 일반 텍스트 추출로 복원되지 않을 수 있다. 원본 지면을 읽어 전사한다. 기존 자동 수식 병합기는 두 행 C₁,C₂와 bar AB=5를 합친 사례가 있어 패키지에 넣지 않았다.
4. 수식마다 source_page/source_bbox/행 기준선을 기록한다. 원문의 분수 분자/분모, 음수 지수, 첨자, 윗줄, 벡터, 프라임, 절댓값, 집합 연산, 소괄호 범위를 확인하고 한글 스크립트로 만든다. 높이가 큰 수식은 실제 분수/행렬인지 다른 행이 섞였는지 구별한다.
5. 원본 지면을 유지할 경우 `prepare_background.py`에 검토된 remove_boxes를 전달한다. 이미지·선·벡터는 유지한다. 본문·수식 전 영역이 제거됐는지 확인하고, OCR이 누락한 윤곽선 글자·그림 안 표기는 별도로 처리한다. 그림 안 표기도 편집 가능해야 하면 표기 영역을 따로 제거하여 본문/수식으로 재작성한다.
6. JSON pages에 원문 순서로 본문과 수식을 배치하고 원본 배경을 지정한다. 여러 PDF는 학년도·과목 대응표와 함께 이어 넣는다. 제공 양식의 이미 편집 가능한 문항은 되도록 필요한 누락 요소만 수정하며 수식 스크립트와 구조를 비교한다. ZIP을 단순 연결해서 section ID·서식 ID 충돌을 만들지 않는다.
7. 원본과 출력본을 쪽별로 대조한다. 쉼표가 A와 B 사이에 있는지, 배점과 안내문이 해당 문항/쪽에 있는지 확인한다. 원본에서 “오른쪽”이면 그대로 쓰고 “다음”으로 임의 변경하지 않는다.

배경 삭제 입력 예:

```json
{"page":1,"remove_boxes":[[60,220,400,260],[440,220,780,265]]}
```

이 박스는 예시다. 문서 전체에 그대로 적용하지 않는다. 배경에 텍스트가 남아 있으면 편집 가능한 본문을 추가해도 편집성이 확보된 것으로 간주하지 않는다. 본문 전체를 래스터 배경으로 남겨두고 수식만 편집 가능하게 만든 방식은 금지한다.
