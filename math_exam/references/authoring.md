# 응용·변형 출제

예시 문항이 주어지면 평가 요소, 풀이 단계, 난도, 교과 범위, 오답의 원인을 먼저 분석한다. 주제만 주어지면 해당 교과에 맞게 새 조건을 설계한다. 요청되지 않은 문항 수를 임의로 확대하지 않는다. 난도와 배점이 불명확하면 요청의 문맥에 맞는 가정을 알린다.

정적분 넓이 문제는 교점→적분 구간→구간별 위/아래 함수→양의 넓이→선택지 검산을 거친다. 두 곡선의 위치가 바뀌는 교점에서 구간을 분리한다. 음의 정적분이나 양·음 상쇄값을 넓이로 쓰지 않는다. 상수 역산 문제는 그래프와 해설에 쓰인 값이 정답과 일치해야 한다. 출제와 독립된 계산 경로로 다시 확인한다. 예제는 `check_examples.py`가 유리수 계산으로 검산한다.

그래프 JSON은 `curves`에 내림차순 다항식 계수, `xlim`/`ylim`, `shade`에 넓이 구간, `verticals`에 [x, y]를 둔다. 선과 음영만 `draw_graph.py`로 생성한다. 함수명·축 이름·좌표·상수·점 이름은 HWPX에서 별도 수식으로 배치한다. 이미지와 수식의 좌표 변환은 아래와 같다.

```text
X = image_x + width * (.08 + .83 * (x-xmin)/(xmax-xmin))
Y = image_y + height * (1-.09-.8 * (y-ymin)/(ymax-ymin))
```

기하/확통 등 다른 그림은 도형 관계, 길이, 각도, 표본 공간을 정확하게 재구성한다. 수학 도식은 좌표 기반 도구를 기본으로 사용한다. AI 이미지가 보기 좋아도 수학적 조건을 검증할 수 없다면 최종 도식으로 쓰지 않는다.

문항 본문, 조건, 선택지, 배점, 정답, 해설, 출제 의도, 독립 검산 결과를 먼저 확정한다. HWPX로 조립하고 실제 출력 지면에서 글자 겹침과 수식 범위를 확인한다. 정답이 유일하지 않거나 범위를 벗어나면 조건을 다시 설계한다. 예제 원고를 재사용할 때 제목과 숫자만 바꾸는 데 그치지 않는다.
