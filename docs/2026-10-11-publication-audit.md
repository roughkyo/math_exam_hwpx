# 공개 배포 점검 — 2026-10-11

이 문서는 최초 공개본 `1.3-public.1`의 과거 점검 기록입니다. 현재 기본 양식과 변경 검증은 [기본 양식 복원 기록](2026-10-11-template-update.md)을 따릅니다. 사용자가 공개 배포를 명시적으로 허용하여 `1.3-public.2`부터 지정 양식을 사용합니다.

## 공개 대상에서 제외

- 원본 시험지 PDF, 3개년 통합본과 모의평가 변환본
- 사용자 제공 평가원 양식 및 그 안에 남아 있던 실제 기출 내용
- 개인 작업 기록, 파일 목록, 임시 산출물, 이전 검증 로그
- 공개 재배포 허가를 확인하지 못한 양파고 vendor 스크립트
- 한글 프로그램, 별도 폰트 파일, 인증 정보, 의존 라이브러리 바이너리

원래 로컬 패키지는 수정하지 않고 별도 공개 폴더를 구성했습니다. 공개본의 기본 양식은 한글 새 문서에서 생성한 중립 양식입니다. 기존 사용자 양식은 배포받은 사용자가 자기 작업에 별도로 제공할 수 있습니다.

## 개인정보와 문서 내부 검사

- 배포 텍스트의 개인 경로, 로컬 사용자명, 이메일, 전화번호·주민등록번호 형식, 주요 API 토큰과 개인키 패턴을 검사했습니다. 최종 검사에서 해당 패턴 발견 0건입니다.
- HWPX 5개(양식 1개, 예제 4개)의 ZIP 내부 XML·미리보기 텍스트·메타데이터를 검사했습니다. 작성자·최종 저장자 값은 비어 있습니다.
- PDF 예제 4개의 메타데이터·추출 본문을 검사했습니다. 작성자 필드는 비어 있습니다. 제작 프로그램 이름·버전과 생성 일시는 남아 있습니다.
- PNG 메타데이터를 검사했습니다. 포함한 그래프는 패키지의 출제 예제용 그림입니다.
- 공개 커밋은 저장소 소유자의 GitHub noreply 이메일을 사용합니다.

패턴 검사와 메타데이터 검사가 모든 개인정보나 모든 권리 문제의 부재를 보증하지는 않습니다. 원본 기출·권한이 불명확한 vendor를 제외하고 새 양식을 사용해 확인된 공개 위험을 줄였습니다.

## 실행 검사

- `doctor.py`: 필수 라이브러리·새 양식 해시·한글 등록 확인
- `smoke_test.py`: 동일 원고의 바이트 동일 재현, 원본 양식 불변, 기존 파일 덮어쓰기 거부, 미검토 원고 거부
- `check_examples.py`: 정적분 예제 3문항 검산 통과
- `test_layout_guards.py`: 확장 괄호·머리말 경계·바닥글 줄바꿈 회귀 검사 통과
- `test_native_paragraphs.py`: 일반 본문/인라인 수식 검사 및 잘못된 입력 7종 거부
- `test_release.py`: 정상 예제 4종, 본문·수식 변조 거부, 오래된 측정값 거부, 설치 후 manifest 검사 모두 통과
- 새 기본 양식으로 예제 HWPX 4종 재생성 후 실제 한글 PDF 출력 성공(2쪽·1쪽·1쪽·1쪽)
- 정적분 예제 첫 쪽을 렌더링하여 새 제목·본문·그림 배치를 확인

이 기록은 세 에이전트 앱에서 각각 실행한 테스트나 모든 문항의 완전한 시각 검증을 뜻하지 않습니다. 구조 검사에서 긴 수식의 높이 경고 1건이 있었으며, 수식 내용을 분리·삭제하지 않고 그대로 유지했습니다.

## Git 제외 규칙 검사

`input/`, `form/`, `output/`, `work/`, `.env`, `.venv/`, `credentials.json`이 제외되는 것을 확인했습니다. HWPX/PDF는 원칙적으로 제외하고, 검토한 `math_exam/assets/forms/default_exam.hwpx` 및 `math_exam/examples/` 문서만 예외로 허용합니다.

`.gitattributes`로 텍스트 줄바꿈을 LF로 고정하여 Windows 체크아웃에서도 manifest 해시가 유지되도록 했습니다.

## 권리 안내

제3자 자원에 임의의 새 라이선스를 적용하지 않았습니다. 저장소에는 포괄적 MIT 등 라이선스를 추가하지 않았으며, 재사용·재배포 조건이 필요하면 소유자가 별도로 결정해야 합니다. Python 의존성은 각 프로젝트의 라이선스를 따르며 이 저장소에 라이브러리 코드를 묶어 배포하지 않습니다.
