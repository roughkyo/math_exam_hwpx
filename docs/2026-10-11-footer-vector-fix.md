# 바닥글 중복·벡터 상단 잘림 수정 — 2026-10-11

버전: `1.4-public.1`

## 확인한 원인과 수정

1. 바닥글은 PDF에서 윤곽선으로 남아 배경 이미지에도 보였습니다. 그 위에 보통 텍스트를 다시 배치하여 겹쳤습니다. 검토한 문구 영역만 지워 본문 하나만 남겼습니다. 배경 바닥글 영역에 잉크가 남으면 빌더가 거부하도록 추가했습니다. `prepare_background.py`의 `clear_boxes`는 검토한 영역의 윤곽선 글자까지 제거합니다.
2. 벡터는 수식 스크립트가 정확해도 작은 셀과 줄 높이 설정 때문에 화살촉 윗부분이 잘렸습니다. 인라인 문단에 본문·수식의 최대 상단/하단 높이를 반영하고, 셀 위아래 2pt 여백과 `affectLSpacing=1`을 적용했습니다. 셀 위치와 위 여백을 함께 조정하여 기준선을 유지하고 수식 측정 치수는 보존했습니다.

같은 페이지의 동일 저작권 문구는 하나만 남기고 본문이 담당하는 경우 양식 마스터의 문구를 비웁니다. 공유 마스터의 일부 쪽만 제거하여 누락되는 것을 막기 위해 본문/양식 담당이 섞인 원고는 거부합니다. 실제 출력 횟수 검사는 `expected_occurrences: 1`로 지정합니다. 이미지나 윤곽선 중복은 텍스트 개수만으로 찾을 수 없어 별도 배경 검사와 확대 확인을 수행합니다.

## 검증

- 수정 전 실제 한글 PDF에서 잘린 벡터를 재현했습니다. 같은 수식의 독립 개체와 비교한 화살표 상단 검은 픽셀 비율은 수정 전 약 0.493, 수정 후 약 0.989였습니다. 이 수치는 해당 회귀 예제의 잉크 비교값이며 전체 문서 정확도 점수가 아닙니다.
- `test_footer_visibility.py --render`: 작은 셀의 벡터 상단, 바닥글 출력 1회, 배경 잉크 거부, 중복 원고 정리, 혼합 담당 거부를 검사했습니다.
- `test_release.py`, `test_native_paragraphs.py`, `test_layout_guards.py` 통과. 기존 4종 예제도 재생성하고 실제 한글 출력했습니다.
- 사용자 20쪽 시험지에 적용하여 수식 564개·배점 46개·원고 본문 514개를 대조했습니다. 이전 출력과 20쪽 문자 빈도가 동일합니다. 모든 쪽의 배경 바닥글 영역을 비우고 출력 텍스트의 문구가 쪽마다 한 번인지 확인했습니다.
- 실제 기하 23번 벡터와 8쪽 바닥글을 확대 확인했습니다. 모든 수식의 개별 픽셀 일치를 보증하지 않습니다.
- 공개 자료의 개인정보 패턴 및 문서 내부 메타데이터 검사에서 새 발견은 없습니다. 사용자 시험지·수정 결과물·개인 검증 로그는 저장소에 포함하지 않습니다.

## 사용

```text
python math_exam/scripts/test_footer_visibility.py --work work/new-visibility-check --render
```

Windows 한글이 없으면 `--render`를 빼고 구조 검사만 실행합니다. 구조 검사만 통과한 경우 실제 출력 확인을 완료했다고 표시하지 않습니다. 수식 여백을 늘린 뒤 주변 문항·다음 줄·페이지 경계도 확인해야 합니다.

배포 기본 양식은 사용자가 허용한 평가원 수학 양식을 그대로 유지합니다. 변경 파일 전체는 Git 커밋과 `2026-10-11-file-list.txt`, 패키지 내부 해시는 `math_exam/manifest.json`에서 확인할 수 있습니다.
